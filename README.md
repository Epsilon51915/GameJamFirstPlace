# Universe Game
## Developers
Developed by Tyler Carroll and Kevin O'Connell
Developed for the UNR 2026 Game Jam

## About Universe Game
Universe Game is a (poorly made demo) factory game at the end of the universe, where very few materials are left. Equipped with nothing but a time machine, the player must harvest resources from what's left at the end of the universe in order to upgrade their tools, upgrade their time machine, and travel back in time to get heavier and rarer materials. Currently, Universe Game has only 2 "time periods," the first giving you access to wood (magic space trees that still exist in the end of the universe,) and iron, and the second giving the player access to aluminum. Should the player harvest the aluminum needed to upgrade the time machine a second time, they will complete the demo.

## Game Jam Theme
The 2026 UNR Game Jam's theme was "back in time," which we took in 2 distinct ways:
1. As demonstrated in the game synopsis, the main goal of the game is to upgrade a time machine and to go back in time to get access to rarer resources.
2. Taking a more literal approach, the game is solely made with ASCII art, making it look and feel similar to something you would experience on DOS-BOX or other older game platforms.
